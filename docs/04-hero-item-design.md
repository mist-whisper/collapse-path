# 英雄与装备设计方向

## 1. 设计目标

崩坏路径不能依赖「所有英雄都能随便送」来运作。  
它需要通过英雄特性与装备选择，形成明确的构建差异和阵容决策。

目标是让玩家在选人阶段就需要思考：

- 我们这局是否准备走崩坏路径？
- 谁来承担主要的战略牺牲职责？
- 敌方如果针对崩坏路径，我们是否有应对手段？

## 2. 英雄定位分类（初版）

建议将英雄大致分为三类亲和度，而非强制绑定。

### 2.1 高崩坏亲和（Collapse Affinity）

这类英雄天生更容易把死亡转化为价值，适合作为崩坏路径的核心执行者。

典型特征：
- 死亡后能留下强力效果（领域、减速、真实伤害、视野、护盾等）
- 技能组鼓励高风险换人
- 复活或买活收益较高
- 在残血或死亡边缘仍有较强干扰能力

适合角色：部分辅助、部分打野、少数特殊战士/法师。

设计意图：让队伍在选人时可以主动选择「我们有专门负责堆积 Ruin 的人」。

### 2.2 中等亲和（Flexible）

大多数常规英雄属于这一类。  
他们可以通过出装和打法临时提升崩坏贡献，但不是最优选择。

设计意图：保证崩坏路径不是只有特定英雄才能玩，普通阵容也有机会切入。

### 2.3 低崩坏亲和 / 反崩坏（Anti-Collapse）

这类英雄更擅长传统统治路径，或者具备压制敌方 Ruin 积累的能力。

典型特征：
- 强推线、强拆塔、强滚雪球
- 能有效限制敌方走位和送死空间
- 具备减少敌方死亡收益的手段（例如降低击杀奖励、缩短死亡时间收益等）

设计意图：给想走传统路径的队伍提供明确的反制工具，避免崩坏路径一家独大。

## 3. 装备系统设计

装备是连接「英雄特性」与「路径选择」的重要桥梁。

### 3.1 崩坏专属/强化装备线

建议增加一条或若干件与 Ruin 强相关的装备，只有在队伍 Ruin 达到一定阈值后才能高效发挥作用。

可能的方向：
- 死亡时额外提供团队增益或真实伤害
- 提升「死亡转化价值」的计算权重
- 在崩坏窗口期间获得额外属性或技能效果
- 将部分经济转化为 Ruin 相关收益

注意：这些装备在传统对局中应该偏弱或性价比一般，防止被无脑选择。

### 3.2 反崩坏装备

领先方或选择传统路径的队伍需要有明确的出装选择来压制敌方 Ruin 增长速度。

可能的方向：
- 降低击杀自己时对方获得的 Ruin
- 缩短自己死亡后的收益窗口
- 提供额外的「镇压」效果（例如附近敌人死亡时 Ruin 获取效率下降）

### 3.3 通用装备的微调

现有部分装备可以考虑轻微调整，使其在不同路径下产生不同价值，例如：
- 某些防御装在残血时提供更强的反打能力（利于高价值交换）
- 某些游走装提升死亡前的控制或视野贡献

## 4. 阵容构建与选人阶段的影响

引入亲和度差异后，选人会多出一层决策：

- 是否抢高崩坏亲和英雄？
- 是否需要预留反崩坏英雄来应对敌方可能的崩坏阵容？
- 辅助和打野的定位会变得更关键，因为他们往往是最适合执行战略牺牲的位置。

高分段可能会出现专门的「崩坏体系」与「纯统治体系」的对抗，类似于现在的速推流 vs 后期团战流。

## 5. 角色职责建议

| 位置 | 在崩坏路径中的典型职责 |
|------|------------------------|
| 辅助 | 最适合承担高频率、高价值牺牲，保护核心的同时堆积 Ruin |
| 打野 | 通过入侵、抢目标和死亡换龙等方式提供高质量 Ruin |
| 中路 | 可灵活选择参与牺牲或保持发育，作为路径切换的枢纽 |
| 上单 | 更多承担带线牵制，或在关键团战中执行一次性高价值换人 |
| 射手 | 通常是被保护的对象，较少主动送死，但可通过位置吸引火力创造牺牲空间 |

## 6. 设计原则

1. **差异化而非强制**：英雄有亲和度倾向，但不应该出现「这个英雄完全不能走某条路径」的极端情况。
2. **出装决定路径强度**：即使是高亲和英雄，也需要通过出装来真正强化崩坏能力。
3. **反制必须存在**：必须给传统路径的队伍留下足够清晰的针对手段。
4. **避免数值膨胀**：新增的崩坏相关效果应尽量通过「转化」和「条件触发」实现，而不是单纯堆高数值。

## 7. 开放问题

- 高崩坏亲和英雄的强度如何控制，才不会变成必抢？
- 崩坏装备的解锁条件设在什么 Ruin 阈值最合适？
- 是否需要为崩坏路径设计专属的召唤师技能或符文？
- 如何在英雄技能描述中清晰传达「这个英雄擅长战略牺牲」？

本文件目前只提供方向性框架，具体英雄案例与装备数值需要在后续版本中逐步补充。
