# 愿景与问题定义

## 1. 我们试图解决什么问题？

在现有主流竞技 MOBA 中，胜利条件高度单一：

- 摧毁对方基地 = 胜利
- 未能摧毁 = 失败

这种设计非常清晰，也支撑了目前的高竞技生态。但它带来了几个长期存在的体验问题：

1. **失败的价值感极低**  
   一旦明显落后，很多玩家会迅速进入「这局没了」的心态。失败本身几乎不产生任何被系统认可的策略价值，只剩下惩罚。

2. **逆风体验单一且容易消极**  
   虽然存在逆风翻盘，但路径仍然是「努力把传统优势追回来」。缺少另一条被规则明确支持的、风格完全不同的求胜方式。

3. **「有价值的死亡」停留在口头认可**  
   高水平玩家都知道「死得值」和「无脑送」的区别，但系统几乎不区分它们。战术牺牲更多依赖玩家默契和赛后复盘，而不是被机制直接奖励。

4. **策略深度被限制在单一胜利框架内**  
   阵容、运营、团战决策最终都服务于同一条路径。如果存在第二条合法且高风险的胜利路径，策略空间会显著扩大。

## 2. 我们想达成什么？

**Collapse Path** 的核心愿景是：

> 在不破坏传统推塔竞技性的前提下，让「战略性、有价值的失败」成为一条被系统正式承认、可以通向胜利的路径。

具体目标：

- **双轨并存**：传统统治路径（Dominion）与崩坏路径（Collapse）都能在高水平对局中成立。
- **失败可被计算**：系统能相对准确地区分「高明牺牲」与「无价值送死」。
- **决策密度提升**：玩家需要时刻判断「现在死值不值」「要不要开始堆积 Ruin」「触发时机是否成熟」。
- **叙事更丰富**：职业赛和解说可以出现「战略性崩盘」「Ruin 反超」「崩坏窗口决战」等新的经典故事。
- **反消极设计**：通过明确奖励有价值的失败，降低「这局没了就摆烂」的心理诱因。

## 3. 明确的非目标（我们不做什么）

为了保持方向清晰，以下内容**不是**本设计的目标：

- 我们不追求「所有人都可以靠故意送赢下来」。无价值送死必须被严厉惩罚。
- 我们不试图取代传统推塔胜利条件。传统路径必须始终是强有力且主流的选择。
- 我们不设计一个鼓励前期彻底躺平的系统。崩坏路径需要有获取节奏和风险。
- 我们暂时不追求做成完整商业游戏。当前阶段只专注把设计概念打磨到足够清晰、可被严肃讨论的程度。
- 我们不假设这个方向一定优于现有 MOBA。它只是一个值得被认真探索的可能性。

## 4. 成功标准（怎样算这个概念成立？）

一个设计方向是否值得继续，可以用以下几个标准初步判断：

1. **策略真实性**  
   在高水平玩家手中，崩坏路径是否能成为经过计算后的合理选择，而不是纯赌博或娱乐梗？

2. **可区分性**  
   系统是否能在大多数情况下，把「战略牺牲」和「摆烂送人头」区分开？

3. **对抗性**  
   领先方是否拥有足够清晰的手段去压制或应对敌方的崩坏路径？

4. **观赏性**  
   一场围绕 Ruin 展开的对局，是否能产生比普通逆风翻盘更有记忆点的叙事？

5. **心理影响**  
   玩家在明显落后时，是否更愿意继续认真寻找「有价值的失败」机会，而不是直接放弃？

如果以上多数问题的答案是「有希望成立」，这个方向就值得继续投入。

## 5. 设计哲学

- **失败不是终点，而是一种可被转化的资源**（前提是失败有价值）。
- **清晰优于复杂**：机制必须能被普通玩家在几局内理解核心逻辑。
- **竞技性优先**：任何增加趣味的设计，都不能以牺牲排名公平和反作弊为代价。
- **保持克制**：只增加真正必要的系统，避免为了「创新」而堆砌机制。

## 6. 当前阶段的定位

本仓库记录的是一个**开放的设计概念**，而不是已经验证的成品。

我们欢迎尖锐的批评，尤其是：
- 指出这个方向在竞技环境下必然会崩溃的理由
- 提出更干净、更难被钻空子的替代实现方式
- 补充我们尚未考虑到的边界情况

只有经过足够多的质疑与迭代，这个想法才有资格进入原型阶段。
