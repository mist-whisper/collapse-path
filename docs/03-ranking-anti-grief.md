# 排名、评分与反摆烂设计

## 1. 核心挑战

引入「战略性失败可转化为胜利」的机制后，最大的风险不是机制本身好玩与否，而是：

> 系统能否稳定区分「高明的战略牺牲」和「故意送人头」？

如果区分失败，会出现以下问题：
- 玩家通过无脑送死来堆积 Ruin，破坏对局体验
- 排名系统被污染，真正实力强的玩家反而吃亏
- 匹配质量下降，玩家对「这局是否认真」失去信任

因此，评分与反摆烂必须从设计第一天就优先考虑，而不是事后补丁。

## 2. 双维度个人评分

建议将玩家的单局表现拆成两个独立维度，再综合计算最终表现分。

### 2.1 传统贡献分（Traditional Contribution）

衡量玩家在传统胜利路径上的表现，包括但不限于：
- 击杀、助攻、伤害、承伤
- 经济转化效率（补刀、野区、推塔参与）
- 视野贡献、控制时长、关键技能命中
- 对团队目标的实际推进作用

这部分与现有 MOBA 的评分逻辑基本一致。

### 2.2 战略牺牲效率（Strategic Sacrifice Efficiency）

专门衡量「失败」是否产生了价值。核心指标建议包括：

| 指标 | 说明 | 权重参考 |
|------|------|----------|
| 死亡转化价值 | 死亡前后是否成功转化为击杀、防御塔、龙等目标 | 高 |
| 交换质量 | 死亡时造成的伤害、控制、资源交换比 | 高 |
| Ruin 贡献纯度 | 该玩家提供的 Ruin 中，有多少来自高价值行为 | 高 |
| 低价值死亡惩罚 | 连续或无贡献死亡会显著扣分 | 极高（负向） |
| 时机判断 | 是否在正确的节奏点选择牺牲（例如为了保核心或抢目标） | 中高 |

**关键原则**：  
战略牺牲效率看的是「每次死亡带来的平均团队收益」，而不是死亡次数本身。死得越多，如果平均价值低，分数会大幅下降。

## 3. 如何识别「无价值送死」

系统需要结合多种信号进行判断，而不是只看单一数据：

1. **死亡时的行为上下文**
   - 死亡前 3–5 秒是否有有效输出或控制
   - 是否处于有目标可转化的位置（靠近龙坑、防御塔、兵线）
   - 队友是否因这次死亡获得了明显收益

2. **连续模式检测**
   - 短时间内多次低价值死亡
   - 死亡位置高度重复且无战术意图
   - 与队友的距离和行动完全脱节

3. **Ruin 贡献质量**
   - 如果一个玩家贡献了大量 Ruin，但这些 Ruin 几乎全部来自无交换死亡，则判定为低质量贡献，并大幅降低其战略牺牲效率分

4. **事后团队收益验证**
   - 死亡后 10–15 秒内，队伍是否真正获得了目标或经济优势
   - 如果没有，这次死亡的价值会被回溯下调

## 4. 排名与段位影响

### 4.1 单局表现分计算（示意）
```text
最终表现分 = 传统贡献分 × a + 战略牺牲效率分 × b - 低价值死亡惩罚
```
其中 a 和 b 的权重需要根据模式调整。在崩坏路径触发的对局中，战略牺牲效率的权重可以适当提高。

### 4.2 对段位的影响
胜利时：两个维度表现都优秀的玩家获得更高加分
失败时：如果战略牺牲效率极高，且团队最终触发了崩坏路径，可以获得比普通失败更少的扣分，甚至少量加分（类似现在的败方 MVP 补偿，但更精准）
故意低价值送死的玩家：无论胜负，都会受到额外的表现分惩罚，并可能触发行为警告

### 4.3 匹配相关
短期行为分（基于最近若干局的低价值死亡率）可以轻微影响匹配
但不建议做成「Loser Queue」式的惩罚匹配，以免引发更大的不信任

5. **激励与惩罚措施**

***正向激励***

高战略牺牲效率的玩家在结算时获得明确展示（例如「高价值牺牲」标签）
连续多局保持高效率牺牲的玩家，可获得额外的赛季成就或展示性奖励
在崩坏路径成功的对局中，核心贡献者获得更高的表现认可

***负向惩罚***

单局低价值死亡超过一定阈值：结算时强制降低表现分
多次触发低价值死亡模式：进入行为观察期，严重时限制排位
与现有挂机、辱骂等惩罚系统打通，形成统一的行为管理体系

6. **已知难点与开放问题**
   - 价值量化的准确性

「死亡转化价值」如何定义才足够客观？目前仍需大量对局数据来校准。
   - 误伤高水平牺牲

有些看似冲动的死亡，事后证明是正确的。系统需要保留一定的容错，避免惩罚真正的高决策玩家。
   - 数据透明度

玩家是否应该能看到自己的「战略牺牲效率」明细？完全透明可能帮助学习，也可能被用来钻空子。
   - 新模式与主模式的隔离

如果本系统先作为独立模式上线，行为分是否应该与主模式互通？

7. **设计原则总结**
   - 奖励的是「平均每次失败的价值」，而不是失败的次数。
   - 惩罚必须足够重，才能遏制投机行为。
   - 评分维度要尽可能可解释，让玩家知道自己为什么被加分或扣分。
   - 反摆烂的优先级高于「让机制看起来更酷」。

本系统的目标不是消灭所有死亡，而是让每一次死亡都尽可能成为有意义的决策。
