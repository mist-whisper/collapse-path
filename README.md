# Collapse Path

> 一个探索「战略性失败可转化为胜利路径」的竞技 MOBA 设计概念。

## 这是什么？

传统 MOBA（如《王者荣耀》《英雄联盟》《Dota 2》）几乎只有一条胜利路径：**摧毁对方基地**。  
失败通常只意味着「你输了」，缺少被系统认可的策略价值。

**Collapse Path** 试图回答一个问题：

> 能否在保持高竞技性的前提下，让「有价值的失败」成为通往胜利的另一条合法路径？

本仓库记录的是一个**双轨胜利系统**的设计概念，核心是引入 **Ruin（崩坏）** 资源，让队伍可以在传统推塔路线之外，选择通过战略性牺牲与受控崩盘来积累优势，并在关键节点触发翻转。

这不是一个已经完成的游戏，而是一个开放的设计文档与讨论空间。

## 核心主张

- 失败本身可以具备策略价值，而不仅仅是惩罚。
- 「故意输」和「高明牺牲」必须被系统明确区分。
- 两条胜利路径都需要能支撑高水平竞技与职业赛叙事。
- 设计必须优先考虑反摆烂、排名公平性和观赏性。

## 为什么这个方向有价值？

目前主流竞技 MOBA 中，几乎没有正式把「战略性失败」设计成独立或并行胜利条件的模式。  
最接近的只是战术层面的「有价值死亡」（例如 Dota 中的牺牲换龙），但最终目标依然是传统推塔。

这个设计空间在实时团队竞技游戏中基本仍是空白。
